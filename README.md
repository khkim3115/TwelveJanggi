# 王 십이장기

3×4 판 위의 **王·將·相·子** 네 말로 두는 작은 장기를 웹에서 즐깁니다.
**혼자 하기**(쉬움·보통·어려움 AI), **온라인 1:1 대전**(방 코드), **앱 설치(PWA)** 를 지원합니다.

🔗 **바로 두기**: <https://khkim3115.github.io/TwelveJanggi/>

React 19 + Vite + TypeScript. AI 는 **알파베타 + 반복심화 + 전치표** 탐색 엔진이 Web Worker 에서 돌고,
온라인 대전은 **Supabase(Postgres + Realtime)** 가 규칙까지 검증하는 서버 권위 구조입니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
```

빌드 / 미리보기 / 테스트:

```bash
npm run build      # 타입체크 + vite build → dist/
npm run preview    # PWA 설치·오프라인은 dev 가 아니라 여기서 확인(dev 에서는 서비스 워커가 꺼져 있다)
npm test           # vitest — 규칙 계약 · AI 강도 회귀 · 스토어 계약 · 표기 가드
npm run test:sql   # 서버(plpgsql)·클라이언트 규칙 일치 — 로컬 Postgres(PGlite), 아래 '규칙 일치 검증'
```

## 게임 규칙

가로 3칸 × 세로 4칸 판. 각자 가까운 맨 끝 줄이 자기 **진영**이고, 말은 모두 **한 칸씩** 움직입니다.

| 말 | 움직임 |
|---|---|
| 王 왕 | 8방향 |
| 將 장 | 앞·뒤·왼쪽·오른쪽 |
| 相 상 | 대각선 |
| 子 자 | 앞으로만. 이동으로 상대 진영에 들어가면 **侯** 로 승격 |
| 侯 후 | 뒤쪽 대각선을 뺀 6방향 |

- **잡기와 손패** — 상대 말이 있는 칸으로 가면 그 말을 잡아 내 **손패**로 만듭니다(侯 는 子 로 돌아옵니다).
  내 차례에 손패 하나를 빈칸에 **놓는 것**도 한 수입니다. 단 **상대 진영에는 놓을 수 없고**, 놓는 것으로는 승격하지 않습니다
  (놓은 子 도 나중에 이동으로 상대 진영에 들어가면 侯 가 됩니다).
- **승리** — 상대 **王 을 잡거나**, 내 **王 이 상대 진영에 들어가 한 턴을 버티면**(입성) 이깁니다.
  둘 수 있는 수가 하나도 없으면 집니다. 장군(체크) 규칙은 없습니다 — 王 을 잡히는 칸으로 옮기는 수도 둘 수 있습니다.
- **무승부** — 같은 국면(판·손패·차례)이 3번 나오면 비깁니다. 시작 국면도 1번으로 셉니다.
  온라인 대전은 판이 끝없이 이어지지 않게 **1000수**에 이르면 무승부로 끝냅니다(사람이 두는 판은 여기까지 가지 않습니다).

**녹**이 언제나 먼저 둡니다. 화면 위쪽 **❓ 도움말**에 규칙·조작이 그림과 함께 정리돼 있고, 혼자 하기를 처음 시작하면 한 번 자동으로 열립니다.
**🌙/☀️** 테마, **📋** 패치노트, **💬** 익명 피드백도 같은 줄에 있습니다.

## 🤖 난이도별 AI

| 난이도 | 탐색 | 성격 |
|---|---|---|
| 쉬움 | 한 수 앞 + 큰 잡음, 20% 확률로 아무 수(王 을 바로 내주는 수는 빼고) | 王 은 지키고 이기는 수는 놓치지 않지만 말을 자주 흘립니다. |
| 보통 | 네 수 앞 알파베타, 단순 평가 + 작은 잡음, 3% 확률로 아무 수(王 을 바로 내주는 수는 빼고) | 말 득실은 챙기지만 입성 위협은 늦게 봅니다. |
| 어려움 | 노드 예산 35만(데스크톱 약 0.6–1.1초)까지 반복심화 + 전치표, 전체 평가 | 걸린 말·王 주변 위험·입성 위협까지 계산하고, 같은 국면이면 늘 같은 수를 둡니다. |

세기는 시간이 아니라 **노드 예산**으로 정해 PC·폰에서 비슷하게 둡니다. 王 을 바로 내주는 수와 한 수 만에 이기는 수는
난이도와 무관하게 탐색의 전술 판정이 알아봅니다([`src/engine/ai.ts`](src/engine/ai.ts)).

**선후공**은 홈과 ⚙️ 설정에서 고릅니다 — **녹**(내가 먼저) · **적**(AI 가 먼저) · **랜덤**(판마다 추첨).
실측([`scripts/bench-seats.ts`](scripts/bench-seats.ts))으로는 같은 난이도끼리 선공(녹)의 승점이 쉬움 50% · 보통 59% · 어려움 71%라,
AI 가 강할수록 먼저 두는 쪽이 유리합니다 — 보통·어려움에서는 적으로 두면 더 어렵습니다. 바꾼 선후공·난이도는 **다음 판부터** 적용됩니다.

**💡 힌트**(H)는 난이도와 무관하게 어려움 예산으로 지금 국면의 최선수를 보여 줍니다(이동은 화살표, 손패 놓기는 놓을 칸).
**↩ 되돌리기**(Z)는 내 마지막 차례로 되감고, **↺ 새 게임**은 N 입니다.

## 🌐 온라인 1:1 대전

홈 → **온라인 대전** → **방 만들기**로 6자리 코드를 받아 친구에게 알려 주면, 친구가 코드로 들어와 방장이 시작합니다.
녹·적은 시작할 때 **무작위**로 정해지고, 방 안에서 채팅도 됩니다.

- 한 수를 **2분** 넘게 두지 않으면 상대가 **시간초과 승리**를 요청할 수 있습니다.
- 대국 중에 나갔다가 같은 코드로 다시 들어오면 자리가 그대로입니다(로비의 참가 칸에 코드가 채워져 있습니다).
- 정적 프론트엔드(GitHub Pages)는 게임 권위를 갖지 않습니다. 이동·놓기·승격·승패·무승부 판정을 전부 Supabase 의
  `SECURITY DEFINER` RPC(`tj_play` 등)가 검증하고, 클라이언트 직접 쓰기는 권한 회수와 RLS 로 막습니다.
- 스키마·RLS·RPC 의 진실원본은 [`supabase/schema.sql`](supabase/schema.sql), 실제로 적용한 마이그레이션은 [`supabase/migrations/`](supabase/migrations) 입니다.
  객체 이름이 전부 `tj_` 로 시작하는 이유는 **요트다이스·나인 멘스 모리스와 Supabase 프로젝트를 공유**하기 때문입니다
  (그래서 권한은 `tj_` 객체 이름을 하나씩 적어서만 바꾸고, 전역 `revoke`·`alter default privileges` 는 쓰지 않습니다).

### 환경변수 (둘 다 공개용 — anon 키는 RLS 와 RPC 검증으로 보호됨)

로컬은 `.env.local`(gitignore 처리됨)에:

```
VITE_SUPABASE_URL=https://<project-ref>.supabase.co
VITE_SUPABASE_ANON_KEY=<anon public key>
```

> `service_role` 키는 **절대** 넣지 마세요. 값이 없으면 혼자 하기는 그대로 되고, 온라인 대전과 💬 익명 피드백 보내기가
> 꺼집니다(피드백 창에는 GitHub 이슈로 등록하는 링크만 남습니다).
> GitHub Pages 빌드는 **repo Variables**(Settings → Secrets and variables → Actions → Variables)에서 읽고, 비어 있으면 배포가 멈춥니다.

### 규칙 일치 검증

서버(plpgsql)와 클라이언트(`src/core`)가 같은 규칙인지 확인합니다. 먼저 DB 없이 로컬에서:

```bash
npm run test:sql                # PGlite(WASM Postgres)에 schema.sql 을 올려 대조 — 빠른 모드(4판 · 표본 국면 5% + 고정 국면 3개, 약 25초)
npm run test:sql -- --deep      # 깊은 모드(60판 · 표본 8%, 약 3–4분)
npm run test:sql -- --sql <파일> # schema.sql 대신 쓸 전체 누적본(초안)으로 — 델타 마이그레이션은 받지 않습니다
```

권한 매트릭스(허용 목록 밖은 전부 회수돼 있어야 합니다), 공개 RPC 시그니처, `tj_can_step` 전수, 판정 순서, 무작위 대국 매 수,
고정·표본 국면마다 가능한 모든 `tj_play` 인자(받는 수 = 클라이언트 합법 수, 결과 = 클라이언트 착수), 방 흐름·제한·CHECK 를 보고,
[`supabase/migrations/`](supabase/migrations) 를 차례로 적용한 결과(= 실서버)가 `schema.sql` 과 같은지도 봅니다.
PR 마다 CI 가 빠른 모드를 돌립니다.

그다음 실제 프로젝트에서:

```bash
npm run e2e:mp                  # 익명 세션 2개 — 입성·3회 반복·王 잡기·승격·놓기·거부 13종·기권 + AI 자가대국, 매 수 대조
npm run e2e:mp -- --timeout     # 시간초과(120초 대기)까지
npm run e2e:mp -- --steps-sql   # tj_can_step 전수(2×5×12×12) 대조 SQL 출력 — SQL 편집기에서 0행이면 일치
```

> ⚠️ 실제 DB 에 방과 익명 사용자를 만듭니다(끝난 방은 24시간 뒤 정리). `src/core` 나 SQL 규칙을 바꿨을 때 돌립니다.

## 📲 앱으로 설치 (PWA)

주소창의 설치(⊕) 아이콘이나 홈의 **⬇ 앱 설치** 버튼(넓은 화면에서는 위쪽 **📥** 도)으로 설치합니다
(iPhone·iPad 는 Safari 공유 → 홈 화면에 추가).
설치하면 주소창 없는 독립 창으로 뜨고, 서비스 워커가 앱을 미리 받아 두어 **혼자 하기는 인터넷 없이도** 동작합니다
(AI 계산이 전부 기기 안에서 일어납니다). 새 버전이 배포되면 홈 화면 아래 알림의 **업데이트**로 적용합니다 —
업데이트는 새로고침이라 대국·대기실 화면에서는 알림을 띄우지 않고, 앱(탭)을 모두 닫았다 다시 열어도 적용됩니다.

아이콘을 바꾸려면 [`public/icon.svg`](public/icon.svg) 를 고친 뒤 `npm run generate-pwa-assets` 를 돌립니다
(설정: [`pwa-assets.config.ts`](pwa-assets.config.ts)).

## 검증

PR 마다 GitHub Actions(`.github/workflows/ci.yml`)가 타입체크 · 테스트 · SQL 규칙 대조(`test:sql` 빠른 모드) · 빌드를 돌립니다.

- **규칙 계약**(`src/core/*.test.ts`) — 말별 이동, 잡기·손패·놓기 금지 줄, 승격(놓기는 승격 없음), 판정 순서와 겹침
  (王 잡기 > 입성 > 반복 > 둘 수 없음), 시작 국면을 포함한 3회 반복, 국면 키의 진법 계약, undo 완전 복원, 증분 해시 = 전체 재계산.
- **AI 강도 회귀**(`src/engine/strength.test.ts`) — 선후공을 번갈아 실제 대국을 돌려 승점 비율(승 1·무 0.5)을 봅니다:
  어려움 vs 보통 ≥ 90%, 보통 vs 쉬움 ≥ 85%, 어려움 vs 쉬움 ≥ 95%.
- **탐색·전술**(`src/engine/search.test.ts`) — *한 수 승리*·*입성 막기*·*투입으로 막기*, 알파베타·전치표가 깊이 1–4 완전 탐색과
  같은 값을 내는지, 어려움의 *결정론*, 탐색 뒤 국면 복원.
- **스토어 계약** — 혼자 하기의 좌석·되돌리기·힌트 흐름, 온라인의 늦은 스냅샷 무시·다른 방 이벤트 무시·전송 중 잠금·재참가.
- **표기 가드**(`src/naming.test.ts`) — 이 게임은 한자 말을 쓰는 십이장기로만 소개합니다.
